# 🍳 Odin Recipes

**Odin Recipes** adalah project website resep sederhana yang dibuat menggunakan **HTML5**.

Project ini dibuat sebagai latihan dasar **Web Development**, khususnya untuk memahami struktur halaman HTML, penggunaan link antar halaman, gambar, list, dan struktur folder.

## 🍽️ Daftar Resep

Website ini memiliki 3 resep:

* 🥣 [Bakso](./recipes/bakso.html)
* 🍜 [Mie Ayam](./recipes/mie-ayam.html)
* 🍚 [Nasi Goreng](./recipes/nasi-goreng.html)

## 📖 Isi Setiap Resep

Setiap halaman resep memiliki beberapa bagian:

* Nama makanan
* Gambar makanan
* Deskripsi
* Bahan-bahan
* Langkah-langkah pembuatan
* Link kembali ke halaman utama

## 📂 Struktur Repository

```text
odin-recipes/
│
├── index.html
│
├── recipes/
│   ├── bakso.html
│   ├── mie-ayam.html
│   └── nasi-goreng.html
│
└── README.md
```

## 🛠️ Teknologi yang Digunakan

* **HTML5**
* Semantic HTML dasar
* Hyperlink
* Images
* Ordered List (`ol`)
* Unordered List (`ul`)
* Basic HTML structure

Project ini **belum menggunakan CSS maupun JavaScript**.

## 🎯 Tujuan Pembelajaran

Project ini dibuat untuk mempraktikkan:

* Membuat struktur HTML dasar
* Membuat beberapa halaman HTML
* Menghubungkan halaman menggunakan `<a>`
* Menggunakan gambar dengan `<img>`
* Membuat daftar menggunakan `<ul>` dan `<ol>`
* Menggunakan struktur folder dalam project
* Membuat website sederhana menggunakan HTML

## 🚀 Cara Menjalankan

### 1. Clone repository

```bash
git clone https://github.com/liAnn09/odin-recipes.git
```

### 2. Masuk ke folder project

```bash
cd odin-recipes
```

### 3. Jalankan website

Buka file:

```text
index.html
```

menggunakan browser seperti Chrome, Edge, atau Firefox.
